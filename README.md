# 📖 Overview

BD Collection is a modern fashion e-commerce platform developed for a real garment business in Bangladesh.

Instead of relying on WordPress or Shopify, this project was built from scratch using a modern React ecosystem and a custom Content Management System (CMS), allowing business owners to manage products, categories, homepage content, branding, and customer inquiries without modifying code.

The application follows a scalable component-driven architecture and is optimized for performance, accessibility, and search engine visibility.

# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/akib2002portfolio-art/bd-collection-storefront.git
```

## Install

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
